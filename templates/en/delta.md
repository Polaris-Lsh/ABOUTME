# Delta — Incremental log (cleared after merge)

> Any agent that notices a change worth recording **appends** it below.
> On merge, the agent follows `WORKFLOW.md`, folds entries into `ABOUTME.md`
> and clears this file.
> Format: `- [YYYY-MM-DD] @agent category: content`; time-bound items: `- [YYYY-MM-DD] @agent category (until YYYY-MM-DD): content`.
> `@agent` = who wrote it — your own name/platform (e.g. `@claude`, `@cursor`, `@opencode`); unsure → any short self-id. It turns this file into a cross-agent timeline and helps settle conflicts at merge time.
> Categories e.g.: project / skill / schedule / preference / environment / correction. Run the routing rule before writing (`WORKFLOW.md` §A).
