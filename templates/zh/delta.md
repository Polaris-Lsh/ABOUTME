# Delta — 增量日志（合并后清空）

> 任何 Agent 觉察到值得入档的变化，**追加**写在下面；合并时由 Agent 跑
> `WORKFLOW.md` 的流程，把条目并入 `ABOUTME.md` 并清空本文件。
> 格式：`- [YYYY-MM-DD] @来源 类别：内容`；时效条目：`- [YYYY-MM-DD] @来源 类别(至 YYYY-MM-DD)：内容`。
> `@来源` = 谁写的——你自己(Agent)的名字/平台(如 `@claude`、`@cursor`、`@opencode`)；不确定就写个简短自称。它让本文件成为一条跨 Agent 时间线，合并时也便于裁决冲突。
> 类别例：项目 / 能力 / 日程 / 偏好 / 环境 / 修正。写入前先过分流判据（`WORKFLOW.md` §A）。
